# Santa Brígida con Vinos 2026

Web estática del programa Santa Brígida con Vinos (1–29 de noviembre de 2026). Dominio: santabrigidaconvinos.es

- `index.html`: toda la web. Los eventos y la configuración (correo, PDF, redes, colaboradores) se editan en los bloques `CONFIG` y `EVENTOS` del script.
- `img/`: carteles de cada evento (`NN-nombre.jpg`, 900×1125), portada (`hero.jpg`, `hero-m.jpg`) e imagen para redes (`og.jpg`).

Publicada en Cloudflare Pages, sin paso de compilación.
